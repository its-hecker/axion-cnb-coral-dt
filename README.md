# AxionOS coral device tree

Staging device tree for Google Pixel 4 XL (coral), to be migrated from [`its-hecker/evox-coral-dt`](https://github.com/its-hecker/evox-coral-dt) and adapted for AxionOS.

**Status:** bootstrap only. AxionOS Android 17 sources are not yet verified usable; do not treat this branch as bootable.

The EvoX tree contains the existing 3D Face Unlock, Motion Sense and Google Camera integration and must be preserved through the port. Validation and actual boot testing are still required.
